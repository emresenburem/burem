Bu taskta sadece marka logolarının olduğu carousel/slider bölümünü düzelt. Önceki denemelerde prompt uygulanmış gibi görünse de sonuç ekranda değişmedi. Bu yüzden bu işi sadece CSS ekleyip bırakma; ilgili componenti gerçekten bul, aktif olarak neyin boyutu/blur’ı bozduğunu tespit et ve doğrudan düzelt.

AMAÇ:
Mobil görünümde marka logolarının bazıları çok küçük, bazıları çok büyük, bazıları ise bulanık görünüyor. Tüm logolar optik olarak dengeli, net ve aynı görsel ağırlıkta görünmeli.

KRİTİK:
Sorun büyük ihtimalle sadece img max-width değil. Muhtemel nedenler:
- carousel active item scale efekti
- opacity/blur transition
- logo dosyalarının iç whitespace farkı
- parent container width farkı
- slide bazlı transform
- Next/Image ya da img wrapper kaynaklı sizing problemi
- duplicate CSS override
- responsive breakpoint override
- framer-motion / embla / swiper / custom slider effect

YAPILACAKLAR:

1) İlgili logo carousel componentini bul.
- Marka logolarının render edildiği gerçek dosyayı tespit et.
- Orada logoları map eden yapıyı incele.
- Eğer active slide’a özel scale, blur, opacity, translate, zoom efekti varsa kaldır.
- Logo bölümünde tüm logolar aynı netlikte ve aynı opacity’de olsun.
- Aktif logo büyümesin, pasif logo küçülmesin.

2) Her logo için sabit bir logo slot sistemi kur.
Her logo aynı boyutta bir slot içinde ortalansın.

Mobil logo slot:
width: 110px;
height: 52px;

Desktop logo slot:
width: 130px;
height: 60px;

Slot stilleri:
display: flex;
align-items: center;
justify-content: center;
flex-shrink: 0;
overflow: hidden;

3) img/logo elemanı için:
width: auto;
height: auto;
object-fit: contain;
display: block;

Mobil:
max-width: 92px;
max-height: 34px;

Desktop:
max-width: 108px;
max-height: 40px;

Kesinlikle object-fit: cover kullanma.
Aspect ratio bozma.

4) Blur ve benzeri tüm efektleri kaldır.
Logo elemanında, slide elemanında ve parent wrapper’da aşağıdakileri kontrol et:
- filter: blur(...)
- backdrop-filter
- opacity düşürme
- scale transform
- motion blur veren transform animation
- CSS transition yüzünden bulanıklık
- transform: scale(...) ile aktif item büyütme
Logo alanında bunların hiçbiri kalmasın.

5) Sadece ortak CSS verme; marka bazlı optik düzeltme yap.
Logo dosyalarının iç boşlukları farklı olduğu için hepsi aynı px ölçüsünde olsa bile farklı büyük görünür. Bu yüzden brand datasına bireysel scale ekle.

Örnek veri yapısı:

{
  name: "ABB",
  logo: "...",
  scale: 0.9
},
{
  name: "Baumuller",
  logo: "...",
  scale: 1.3
}

Render örneği:
<div className="logo-slot">
  <img
    src={brand.logo}
    alt={brand.name}
    style={{
      transform: `scale(${brand.scale ?? 1})`,
      transformOrigin: "center center"
    }}
  />
</div>

ÖNEMLİ:
scale yalnızca logonun kendi görselini büyütsün/küçültsün.
Slot ölçüsü, spacing, layout ve hizalama değişmesin.
